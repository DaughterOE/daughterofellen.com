# Daughter of Ellen

Website for Daughter of Ellen — Africa's growing movement for neurodivergence and persons with disabilities.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local Development

Requires Node.js & npm (install with [nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Install dependencies
npm install

# Start the dev server
npm run dev
```

## Build

```sh
npm run build
```
